# Захист CyberLauncher (5–10 хв)

1. Логотип CyberLauncher, команда CyberLeaks.
2. Проблема: ручний пошук модів, перевірка версій, перенесення файлів. Наше рішення: інтегрований Modrinth.
3. Показ головного екрана: версія, Vanilla/Fabric.
4. Показ каталогу модів та збірок; налаштування RAM, мови, журнал.
5. Технології: C++17, Qt Widgets, CMake, libcurl, Modrinth API.
6. Перспективи: покращення сумісності, інтерфейсу і керування профілями.
7. За запитом викладача: [усі практичні](../CyberLauncher_Labs.md), [реліз](https://github.com/DenyRun0/CyberLauncher/releases/tag/v3.1-build-8), [CI](https://github.com/DenyRun0/CyberLauncher/actions/runs/45637979290), [Kanban](KANBAN.md).

Перед захистом перевірити встановлення релізу на демонстраційному комп'ютері, мережу та право використання гри. Живу демонстрацію провести під час захисту.
