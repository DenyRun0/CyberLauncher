# Інструкція користувача

[Реліз v3.1-build-8](https://github.com/DenyRun0/CyberLauncher/releases/tag/v3.1-build-8). Windows: розпакувати CyberLauncher-windows.zip, відкрити exe. macOS Intel: CyberLauncher-macos-intel.zip; Apple Silicon: CyberLauncher-macos-arm64.zip; ціль macOS 12+. Пакети мають ad-hoc підпис, не нотаризовані Apple. Не вимикайте захист системи. Для гри необхідне законне право користування Minecraft.

- Грати: вибрати версію, Vanilla або Fabric, нікнейм, натиснути «Грати».
- Моди: знайти сумісний мод у Modrinth, встановити, переглянути список, увімкнути/вимкнути або видалити.
- Збірки: знайти збірку, встановити, вибрати її на головному екрані.
- Налаштування: RAM, мова, снапшоти, папка гри.
- Журнал: перегляд статусів та помилок.
